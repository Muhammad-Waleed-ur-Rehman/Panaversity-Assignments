# Task 3 Report

## Project title and what it does
Skill + Connector Workflow — this combines the email-writing skill with the Google Drive connector so a natural sentence can pull live content and turn it into a professional email.

## AI tools and apps used
- Professional Email Writer skill
- Google Drive connector
- AI assistant : Claude.ai

## Prompts used and how they were refined
- Initial prompt: “Open my connected Google Drive file and write a professional email summarizing the key points.”
- Refinement: I made the request more specific so the skill would clearly format the resulting email.

## How I tested or verified it worked
I verified the result by checking that the output matched the source material and still followed the skill’s professional email format.

## What worked, what did not, and problems faced
- Worked well: the workflow connected the skill and connector smoothly.
- Problem faced: the result needed a clear prompt to make sure the skill handled the retrieved content correctly.
