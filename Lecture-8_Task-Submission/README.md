# Lecture 8 Task Submission

This repository contains the complete five-part assignment for Skills & Connectors, adapted to a professional email-writing skill and a Google Drive connector.

## Projects included
- Task 1: Build a professional email-writing skill.
- Task 2: Connect Google Drive in read-only mode and retrieve real data safely.
- Task 3: Combine the email skill and the Google Drive connector in one workflow.
- Task 4: Test portability by checking the skill in chatgpt.
- Task 5: Audit a skill for safety before trusting it.

## AI tools and apps used
- Claude.ai Chat for drafting the skill and prompts
- Google Drive as the connector app
- Chatgpt

## Repository structure
- task-1-my-skill/ — reusable professional email-writing skill, documentation, and task report
- task-2-connect-app/ — read-only Google Drive connector notes and task report
- task-3-skill-plus-connector/ — combined skill-plus-connector workflow example and task report
- task-4-portable-handoff/ — portability and chatgpt testing notes and task report
- task-5-skill-audit/ — safety assessment of a skill and task report
- report.md — overview report for the full assignment
