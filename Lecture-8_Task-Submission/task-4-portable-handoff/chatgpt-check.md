# Chatgpt Check

## Purpose
This note records a simple portability test for the professional email-writing skill in chatgpt 

## Suggested prompt
Write a professional email about a student requesting a short extension for a project deadline.

## Expected result
chatgpt should produce:
- a subject line
- a polite greeting
- a concise body
- a professional closing

## Verification note
If the output matches the expected format, the skill is portable and works outside the original chat.
