# Task 2 Report

## Project title and what it does
Google Drive Connector — this project uses a read-only connector to access a real file safely without changing its contents.

## AI tools and apps used
- Google Drive
- AI connector workflow

## Prompts used and how they were refined
- Initial prompt: “Summarize my most recent Google Drive document and extract the important details.”
- Refinement: I focused on asking for a summary that could be verified against the source file.

## How I tested or verified it worked
I checked the result against the actual document content to confirm that the connector retrieved real data rather than invented information.

## What worked, what did not, and problems faced
- Worked well: the connector was able to retrieve real content safely.
- Problem faced: I had to be careful to keep the permission read-only and avoid any action that would require write access.
