# Task 2 — Connect One App, Read-Only

## App connected
Google Drive.

## Permission granted
Read-only access to view a recent document or file without changing its contents.

## Why read-only is enough here
Read-only access is sufficient for retrieving and summarizing information. Write permission would only be needed if the AI were asked to edit, create, or move files.

## Example prompt
“Summarize my most recent Google Drive document and extract the important details.”

## Verification
I verified the result by comparing the AI summary with the actual Google Drive file content.
