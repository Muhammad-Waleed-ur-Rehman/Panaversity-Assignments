# Task 1 — Build Your First Real Skill

## Chosen skill
I created a professional email-writing skill that turns rough notes into polished email drafts.

## Why this skill is useful
This helps me quickly draft professional emails for class, work, or formal follow-ups.

## Output format
- A short subject line
- A polite greeting
- A concise body with the main purpose
- A professional closing

## Prompts used
1. Initial prompt: “Create a skill that writes professional emails from rough notes.”
2. Refined prompt: “Make the email concise, formal, and ready to send.”
3. Final prompt: “Use a polite tone, include a subject line, and keep the email brief.”

## How I verified it
I checked that the skill would trigger from natural phrases such as “write a professional email about this” and produce a consistent output format.

## Notes
The skill is stored in the SKILL.md file in this folder.
