# AI Client Projects — Muhammad Waleed-ur-Rehman

This repository is organized for four practical AI projects using the **client, not coder** approach: clearly describing a real problem, asking AI to build a solution, testing it against known facts, and documenting prompt improvements.

## Projects

1. [Money Detective](project-1-money-detective/project-1-money-detective/) — analyzes a bank statement for recurring commitments, possible duplicate charges, and spending patterns, with full balance reconciliation.
2. [What's My Grade, Really?](project-2-whats-my-grade/project-2-whats-my-grade-really/) — calculates a student's true grade by encoding teacher-specific rules including dropped scores, weighted categories, conditional exam replacement, and participation bonus.
3. [The Books Don't Match](project-3-books-dont-match/project-3-the-books-dont-match/) — reconciles a hand-counted farewell-gift roster total against a messy digital payment export, identifying duplicates, partial payments, combined transfers, and unidentified funds.
4. [Organize the Mess](project-4-organize-the-mess/project-4-organize-the-mess/) — inventories a cluttered folder, detects duplicates and file categories using SHA-256 hashing, and reorganizes files into a clean output directory through a safe dry-run and approval-controlled copy workflow.

## AI Tools Used

- ChatGPT — requirements clarification, Python code generation, debugging, verification logic, prompt refinement, and documentation across all four projects.

## Current Status

All four projects are complete. Each includes the working script, source data, prompts, generated results, verification, and screenshot evidence.
